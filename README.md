House Price Prediction using Machine Learning

1. Introduction
This project predicts house prices using machine learning. It uses features like area, number of bedrooms, and bathrooms to estimate the price of a house.

2. Objective
Analyze housing data
Build prediction models
Compare model performance

3. Dataset
The dataset includes:
Area
Bedrooms
Bathrooms
Stories
Parking
Furnishing status
Target: House Price

4. Tools Used
Python
Pandas and NumPy
Matplotlib and Seaborn
Scikit-learn

5. Steps
Data cleaning and preprocessing
Data visualization
Model training
Model evaluation

6. Models Used
Linear Regression
Gradient Boosting

7. Evaluation
Mean Absolute Error (MAE)
Root Mean Squared Error (RMSE)

8. Result
Gradient Boosting performed better than Linear Regression.

9. Conclusion
Machine learning can be used to predict house prices effectively, especially with the right model and clean data.
